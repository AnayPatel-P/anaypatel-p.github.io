InvestEdge

Forecasting, honestly. An educational stock app that runs four forecasting models on every S&P 500 stock, then replays a year of their old forecasts against what really happened.

Status
Live · Nov 2026

Live demo (opens in a new tab) Source (opens in a new tab)

How it works
Stack
Python, DuckDB, statsforecast, Prophet, arch, React, FastAPI, Claude API, GitHub Actions

Nightly GitHub Actions pipeline → DuckDB → ~3,000 static JSON files → React on GitHub Pages. ARIMA, ETS, Prophet and GARCH, backtested with a leakage test. Signature interaction, “Rewind & Release”: the chart works like a barograph drum. Drag or flick it back to a past forecast date (1:1 tracking, spring snap, rubber-band ends), and the models’ futures are pencilled in while reality inks itself through them. An outlook strip counts how many of those futures end higher, next to the model’s real track record. Optional Claude tutor that looks numbers up instead of guessing and declines buy/sell questions.

MarketLens

A stock dashboard that writes its own headline. Live watchlist, technical charts and real portfolio P&L, measured against the same money in the S&P 500.

Status
Live · Nov 2026

Live app (opens in a new tab) Source (opens in a new tab)

How it works
Stack
FastAPI, pandas, WebSockets, React, TypeScript, Supabase, Alpaca, Fly.io, Playwright

Rebuilt from scratch. FastAPI computes indicators and average-cost P&L server-side (Wilder RSI checked against the textbook; Decimal math tested against hand-worked trades). One upstream Alpaca stream fans out to every browser over a shared WebSocket. Watchlists and trades live in Supabase under row-level security, proven by a check against the real project. Scrub the chart and the headline rewrites itself; four switchable “lenses”, all WCAG AA. One-click demo, no sign-up.
