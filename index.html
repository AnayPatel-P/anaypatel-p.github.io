InvestEdge

Forecasting, honestly. An educational stock app that runs four forecasting models on every S&P 500 stock, then replays a year of their old forecasts against what really happened.

Nightly GitHub Actions pipeline → DuckDB → ~3,000 static JSON files → React on GitHub Pages. ARIMA, ETS, Prophet and GARCH, backtested with a leakage test. Signature interaction, “Rewind & Release”: the chart works like a barograph drum. Drag or flick it back to a past forecast date (1:1 tracking, spring snap, rubber-band ends), and the models’ futures are pencilled in while reality inks itself through them. An outlook strip counts how many of those futures end higher, next to the model’s real track record. Optional Claude tutor that looks numbers up instead of guessing and declines buy/sell questions.

MarketLens

A stock dashboard that writes its own headline. Live watchlist, technical charts and real portfolio P&L, measured against the same money in the S&P 500.

Rebuilt from scratch. FastAPI computes indicators and average-cost P&L server-side (Wilder RSI checked against the textbook; Decimal math tested against hand-worked trades). One upstream Alpaca stream fans out to every browser over a shared WebSocket. Watchlists and trades live in Supabase under row-level security, proven by a check against the real project. Scrub the chart and the headline rewrites itself; four switchable “lenses”, all WCAG AA. One-click demo, no sign-up.

How I build with AI

I don’t just prompt. I write Claude skills: reusable workflows with phases, gates, output contracts and guardrails. Each one encodes a way of working I’d want from a strong teammate.

Fig. 1

  • Discover

    Evidence-based idea generation. Mines Reddit, Hacker News, forums and reviews for problems people actually complain about, checks each against existing products, and ranks the gaps. No idea makes the report without evidence links.

    10 Discover → 20 Plan

  • Plan & build

    Takes a raw idea to a shipped product through gated phases: clarifying questions, a MoSCoW-prioritized PRD, a roadmap where every phase ends in a demo, then build with check-ins. New asks go through a change-request flow instead of creeping in.

    20 Plan → 30 Design → 40 Build → 50 Shipped

  • Design

    Interviews for the feel you want, researches real interfaces, and combines them into a concept nobody’s seen. It then holds that concept to Apple-grade craft: purpose-driven hierarchy, interruptible motion, designed states, accessibility. This page was made with it.

    30 Design → 40 Build → 50 Shipped

  • Agents

    Turns a task into a well-built agent: a focused role, a system prompt with an output contract, least-privilege tools, the right model, and test cases that prove it works. It suggests changes freely but applies them only with consent.

    feeds 40 Build

  • Learn

    A tutor with three modes: a quick briefing, a project-ready deep dive, or guided questions that map what you already know before teaching what you don’t.

    feeds 40 Build

  • Stay current

    My daily AI newsletter. Three scout sub-agents each sweep one beat (labs, papers, GitHub, forums) and verify every item against a primary source. The skill then writes an issue with a concept, an exercise and a paper explained.
